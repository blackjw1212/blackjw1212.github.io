# 自製浮標的 3D 列印（FDM / Bambu Studio）

這份文件只講**列印出來的東西好不好**。浮力、目標質量、配鉛試算**不在這一輪**，
但其中一項會在這裡做掉：**水密性**。理由見最後一節。

對象是一顆逆向自 **SHIMANO ZERO-PIT TYPE-D 0号 M** 的阿波，Fusion 組合件名稱 `阿波－M`，
兩個零件：

- **`主體`**：標身。Sketch → Revolve 旋轉體，再用 Fillet／Chamfer 修邊。
  **實心，沒有抽殼**（見第 1 節的量測；特徵清單裡有 OffsetFaces，但那不是拿來抽殼的）。
- **`棒`**：中通管，穿過主體、從底部再伸出 6.93 mm。

## 0. 這份文件裡的數字分三種

| 標記 | 意思 |
|---|---|
| **實測** | 從你的 STL 量出來的，2026-10-27 |
| **事實** | 製程或材料的性質，換一台機器也成立 |
| **起始值** | 從這裡開始試，**要靠實測校正**，不要當成答案抄 |

沒有標記的句子一律當成「起始值」。這一頁刻意不給任何「印出來會是幾公克」的預測
——那個數字 Bambu Studio 自己會算，磅秤會定案，這裡猜它只會多一個錯來源。

## 1. 實測：你的 STL 量出了什麼

```
node scripts/float-print-geom.mjs <匯出的 STL>
```

單位是 **mm**——不是猜的，同一次匯出的 STEP 檔頭寫著 `SI_UNIT(.MILLI.,.METRE.)`。

| 項目 | `主體` | `棒` |
|---|---|---|
| 外廓 | 25.27 × 25.26 × 31.75 mm | φ7.00 × 37.92 mm |
| 體積 | 10.381 cm³ | 0.640 cm³ |
| 網格 | 閉合、無非流形邊 | 閉合、無非流形邊 |

**`主體` 的截面是 C 字形。** 沿四個方位角逐 2 mm 切片，每一層都只有兩個交點：
中通孔（r = 2.62 mm，φ5.24）與外壁——**中間沒有空腔**。而 θ = 270° 那條射線整條都沒有交點：
那是 ZERO PIT 的**穿線縫**，從中通孔一路開到外壁、**貫穿全高**。

| 量測 | 數值 |
|---|---|
| 最大半徑 | 12.64 mm（z ≈ −4，在中段偏下） |
| 穿線縫寬 | **0.77 mm**（最窄，z ≈ −4）～ 1.21 mm（頂端） |
| 主體中通孔 | φ5.24 |
| 棒外徑（穿過主體那段） | φ4.90 → 設計間隙直徑差 **0.34 mm** |
| 棒的定位凸耳 ／ 主體凹槽 | r 3.45 ／ r 3.50 → 單邊間隙 **0.05 mm** |
| 棒的線孔 | φ2.25 |
| 頂蓋台階肩 | z ≈ 10.57 有一圈**真正水平**的台階面，寬約 **0.7 mm**（r 10.02 → 9.30），外側再以圓角接到 r 10.6 |

**體積有兩種，這顆標剛好不會拿錯。** 抽殼件的 STL 圍出來的是殼的材料體積、不是排水體積；
但 `主體` 沒抽殼，中通孔、穿線縫、棒的線孔都是通水的空間、本來就不在實體裡，
所以 **10.381 + 0.640 = 11.021 cm³ 就是整組完全沒入時的排水體積**——前提是印出來的實體水密
（第 7 節）。這個數字留給浮力那一輪用，這一頁不拿它算任何東西。

## 2. 列印方向：`主體` 倒放（−z）——以實際列印為準

**實測**（你的 3mf，Bambu Studio 02.08.02.61）：build transform 是 `1 0 0 / 0 −1 0 / 0 0 −1`
（繞 X 轉 180°，倒放）、`enable_support = 0`，**倒放、不加支撐，印成功**。
第一層面積 16.21 mm²，跟工具量的 −z 接觸環對得上。

**我上一輪建議直放（+z），被你的實測推翻了**：直放印出來**靠近底面的表面差**——
底部圓弧那一圈（z −14.2 → −9.9，斜率 45–77°）就是直放時要撐、而撐了會留疤的地方。
從幾何預測的「倒放要撐台階肩」也沒有發生：那圈台階只有 0.7 mm 寬、不到兩條擠出線寬，
**實際不撐就自撐住了**。

| 方向 | 要支撐的地方 | 需支撐面積 | 實際 |
|---|---|---|---|
| **−z 倒放** | 頂蓋台階肩（0.7 mm 水平台階＋外側圓角）、頂端最後 1.2 mm | 5.0% | **無支撐印成功** |
| +z 直放 | 底部圓弧：z −14.2 → −9.9，斜率 45–77° | 11.8% | 靠近底面表面差 |
| 側躺（±x／±y） | 到處都是，而且穿線縫變成要橋接的橫槽 | 15–24% | 直接排除 |

**側躺仍然排除**：直立時縫壁是垂直的，一層一層乾淨地長上去；側躺時它變成一條
0.8–1.2 mm 寬、10 mm 深的橫槽，上緣要橋接，幾乎一定會塌或黏死。

**倒放還是要留意頭重腳輕。** 最寬處（r 12.64）離床 21.8 mm，整顆踩在約 16 mm² 的小環上。
你的 P1S 是 CoreXY（熱床只上下動），實測沒有倒；換成床面前後移動的機型（A1 系列）
要多留意。**brim 不要關**（你現在是 `auto_brim`、5 mm）。

**怎麼把工具表格對到 Bambu Studio 的設定。** 工具用的是一般的 45° 門檻（與垂直的夾角）。
Bambu Studio 的「閾值角度」是**從水平面量的**——你的設定是 30°，換成這裡的量法就是
**與垂直 60°**。所以 Bambu 只會替工具表格裡 **60–80° 與 80–90° 那兩欄**生支撐：
`主體` −z 是 3.2%、+z 是 4.6%。

## 3. 模型端要先改的

- **凸耳與凹槽的 0.05 mm 一定會卡住。事實：FDM 的孔會印小、外形會印大**，
  兩邊各偏一點就吃光 0.05 mm。在 Fusion 把主體的凹槽放大，起始值**單邊 +0.15 mm**。
  改模型比靠切片器補償可靠——那個凹槽是中通孔輪廓的一部分，
  X-Y 孔洞補償會不會照顧到它，不要賭。
- **中通孔對棒的 0.34 mm 直徑差**：棒若是買現成的（尺寸準），這個間隙夠；
  **棒若也用 FDM 印，孔變小、棒變粗，間隙可能歸零**。不管哪一種，
  **先印一片 3 mm 高的配合測試件**（只切中通孔那一段）再決定——拿整顆標去試太貴。
- **穿線縫會印得比模型窄。** 縫是負空間，切片器會照實保留路徑，但每側的擠出會往縫裡鼓一點，
  起始值是**比模型窄 0.1～0.2 mm**：最窄處 0.77 → 約 0.55～0.65 mm。
  磯釣道糸 2～3 号的線徑約 0.235～0.285 mm，仍然過得去；印出來用一條線實際試側推進去。
- **第一層的象足效應**：底部那圈接觸環會外擴。切片端有象腳補償，起始值 0.1～0.2 mm。

## 4. 切片端（Bambu Studio）

版本之間的選項名稱會動，下面括號裡是英文原名，找不到中文標籤時照英文找。

**這顆標的質量由切片參數決定。** `主體` 在 CAD 裡是實心的，所以內部是切片器的稀疏填充，
**牆層數、頂／底殼層數、填充密度與圖案就是質量的旋鈕**——一般「調填充改重量」的直覺在這裡成立。
切片後 Bambu Studio 會顯示預估克數；那個數字 = 擠出體積 × 線材設定檔裡的密度（見第 5 節）。
這一輪不定目標克數，但之後浮力那一輪就是在調這幾個旋鈕。

**層高與曲面**
- 底部圓弧（z −14.2 → −9.9）、台階肩、頂蓋最後那段是斜率最大的地方，也是階梯紋最明顯的地方。
  用**可變層高**（Variable layer height）讓這幾段細、中段（z −8 → +10，斜率約 23° 以內）粗。
- 固定層高的起始值：0.4 噴嘴配 **0.08～0.12 mm**。
- 開「**懸垂降速**」（Slow down for overhangs）。

**支撐與附著**
- **倒放不需要支撐**（實測）。若之後改直放或改了外形需要支撐，用**樹狀、只從熱床生成**
  （Tree support／On build plate only）：中通孔是貫穿的、穿線縫是開放的，裡面不該長支撐。
- **一定要 brim**。接觸環只有約 16 mm²，卻要撐起一個 25 mm 寬、31.75 mm 高的零件。

**接縫**
- `主體` 每一層的截面是一個 C：外壁弧 → 縫壁 → 中通孔弧 → 另一側縫壁，連成**一圈**。
  縫的兩個邊角是尖角，Bambu 的「對齊」接縫本來就會往尖角跑——**切完先在預覽裡確認接縫落在縫邊**，
  沒有的話用**接縫塗畫**（Seam painting）把它畫過去。
- 加開**斜接縫**（Scarf joint seam）。縫邊同時是外壁與縫壁的交界，也就是水最容易從縫鑽進填充的地方。

**殼層（水密的部分）**
- 牆層數（Wall loops）**3～4**。注意縫壁與中通孔壁也是「牆」，它們一樣要水密。
- 頂部／底部殼層（Top/Bottom shell layers）**≥ 5**。
- 開「**確保垂直殼層厚度**」（Ensure vertical shell thickness）——
  底部圓弧與頂蓋的淺斜面若少了這個，牆與頂層之間會留下縫。
- 噴嘴溫度略升、速度略降換層間結合。

**流量**
- 做一次流量校準（Flow rate）。流量偏差會同時影響水密性與實際質量，
  而且它是「切片預估克數」與「磅秤實際克數」對不上時的頭號嫌疑。

## 5. 材料

| 材料 | 密度 g/cm³ | 對浮標 |
|---|---|---|
| PLA | ≈ 1.24 | 好印，但會慢慢吸水，一季下來質量會漂 |
| PETG | ≈ 1.27 | 層間結合好、較耐候，但最重 |
| ASA | ≈ 1.07 | 輕、耐紫外線，適合長期泡海水；會翹曲 |
| ABS | ≈ 1.04 | 最輕；翹曲最嚴重 |

密度以**線材設定檔裡的值**為準，上表只是量級。**Bambu Studio 的預估克數 = 擠出體積 × 這個密度**，
密度填錯，預估就跟著錯。

**LW-PLA（發泡 PLA）不要用在這裡。** 兩個理由都是致命的：

1. 發泡率隨噴嘴溫度變，**同一份切片印兩次質量就不一樣**——質量不可重現，
   後續浮力工作等於沒有基準。
2. 發泡體是多孔的，**不可能水密**。

## 6. `棒`：如果也要自己印

**實測**：37.92 mm 高、最寬 φ7，直立時接觸面只有 3.9 mm²（+z）或 7.8 mm²（−z）——
又高又細又踩在一個點上，是整組裡最難印穩的零件。側躺支撐面積跳到 22–24%，而且線孔會變成橫孔。
若要印：**−z（線孔頂端朝下）、加 brim、放慢**。

**線孔 φ2.25 是道糸會一直摩擦的地方。** FDM 的孔壁有層紋，直立印的層紋剛好橫在線的行進方向上。
這是製程的性質；要不要拋光、或改用現成的管，由你判斷。

## 7. 印完怎麼驗

1. **秤乾重**，0.01 g 的磅秤。
2. **漏水測試**：壓到水面下，看有沒有連續氣泡冒出來（氣泡＝有通道）。
   **重點看縫邊與中通孔壁**——那兩處既是牆也是接縫最可能落的地方。
3. **泡 24 小時後重秤**。**Δ質量就是進水量。** 這是水密與否的判定式。
4. 不合格就補外塗層（環氧／UV 樹脂／塗裝）再重跑 1–3。

**事實：FDM 不會因為切片參數調對就變水密。** 層間永遠有微觀縫隙，
參數只能把滲水速率壓低，封層得靠塗裝。這不是設定沒調好，是製程的性質。

## 8. 浮力

浮力的定義、量法、目標克數與 Bambu Studio 的調法，全部在 **`BUOYANCY.md`**。

這一頁只留一句前提：第 7 節的水密測試要先過。`主體` 的內部是稀疏填充，
外皮會滲水的話，水會慢慢灌進填充，排水體積就從外形一路縮向塑膠本身的體積
——浮力會隨著泡水時間一直變，任何號數都定不下來。
