STOCK OBSERVATION

股票觀測

可自訂的台股觀察清單：加權與櫃買指數、收盤與漲跌%、PE／PB／殖利率、距 52 週高、成交額，欄位與全市場清單一致，並可開完整 TradingView 圖表。

  • 只呈現客觀數據，不產生任何買賣訊號。
資料：Worker / TWSE / static fallback
WEATHER

天氣與海象

查看天氣、潮汐、海象與沿岸觀察資訊。

  • 出行前仍應確認官方資料與現場狀況。
資料：CWA through weather proxy
ESP32 FIRMWARE

ESP32 韌體

收錄自製的 ESP32 / ESP32-S3 韌體專案，涵蓋智慧家庭配件、車輛電子與顯示介面，靜態總覽不讀取即時裝置狀態。

  • 不公開裝置部署位置與連線細節。
內容：靜態專案總覽
FORSCAN REFERENCE

FORScan 設定

整理 Ford Focus Mk3.5（2015-2018）以 FORScan 可調整的便利、儀表、影音與保養服務項目，標明模組、修改方式、驗證度與風險。

  • 能用選單就不動 As-Built。
  • 數值逐車不同，僅供觀察參考。
內容：社群交叉比對整理
FLIGHT COST

機票總成本

把票價、行李、附加費、機場交通與轉機風險加總成同一個數字，用來比較不同航班組合的實際負擔。

  • 票價需自行到各查價網站確認。
  • 輸入的資料只留在本機瀏覽器，不上傳。
內容：手動輸入的試算工具
RIDE TELEMETRY

騎乘儀表板

把手機當儀表：GPS 車速與里程、手機姿態換算的傾角、即時 G 力、海拔與行駛時間，並在記錄期間讓螢幕保持常亮。

  • 騎乘中請勿操作手機，設定與校正出發前做完。
  • 數值僅供參考，非儀器級量測。
  • 資料只留在本機瀏覽器，不上傳、不記錄行經路線。
資料：手機 GPS 與姿態感測器
COUPON STACK

優惠疊加

輸入平台與金額，把平台優惠券、信用卡回饋與支付加碼疊起來，算出當下實付與扣掉回饋後的淨成本。

  • 資料是人工核對的快照，過期優惠自動隱藏。
  • 回饋多為事後給付，不等於當下少付。
內容：人工核對的優惠快照
OFFLINE SUBTITLE

字幕生成

選一個本機的影音檔，在瀏覽器裡跑完語音辨識，輸出可逐句校對的繁體中文 SRT。

  • 檔案不會離開這台裝置，沒有上傳、沒有後端。
  • 首次使用需要下載模型，之後由瀏覽器快取。
限制：需要 WebGPU 才跑得順
UNIVERSAL CONVERTER

檔案轉換

圖片互轉、PDF 進出、Word 與試算表。讀檔頭判斷真正的格式，再挑一個常用的輸出當預設。

  • 檔案不會離開這台裝置，全部運算都在瀏覽器完成。
  • 每種轉檔會失去什麼都逐項寫明，不假裝無損。
限制：沒有 OCR，掃描檔抽不到字
